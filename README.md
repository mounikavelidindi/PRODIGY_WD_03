# Tic Tac Toe - Task 03 | SkillCraft Technology Internship

A responsive Tic Tac Toe web application with an unbeatable AI opponent built using Minimax algorithm. Part of SkillCraft Technology Web Development Internship Task 03.

## 🎮 Live Demo
Open `index.html` in your browser or use VS Code Live Server.

## ✨ Features

- **2 Player Mode**: Play with friends locally
- **AI Opponent**: Unbeatable AI using Minimax algorithm
- **Smart Game Logic**: Auto win/draw detection
- **Responsive Design**: Works on mobile + desktop
- **Clean UI**: Modern gradient design with smooth animations
- **Reset Functionality**: Start new game anytime

## 🧠 AI Logic - Minimax Algorithm

The AI predicts all possible moves and chooses the optimal one:
1. If AI can win → It wins
2. If you can win → AI blocks you
3. Otherwise → AI chooses best strategic move

Result: The game always ends in draw if you play perfectly. AI cannot be beaten!
